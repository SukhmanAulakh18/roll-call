# Threat model: OWASP Top 10 for Agentic Applications 2026

**Note:** the ASI01 to ASI10 titles below are taken from secondary summaries and are pending reconciliation with the official OWASP text. Treat the titles and scope of each item as provisional.

Each row: the control in this repository, the test that exercises it (or "not implemented, limit"), and the runbook. The fleet, tools and model responses are simulated; the controls are real code. Results are from one laptop-class machine (see impact.json environment).

| Item | Control in this repo | Test | Runbook |
|---|---|---|---|
| ASI01 Agent Goal Hijack | A hijacked goal is bounded rather than prevented: per-agent tool scopes (`services/gateway/src/policy.ts`), budgets, throttles, scope-drift detector (`services/control/src/detector.ts`). No prompt-level injection filter. | `make drill` (scope-drift); `npm test` (gateway scope denies). Prompt-injection defence: not implemented, limit | [runaway-agent.md](../docs/runbooks/runaway-agent.md) |
| ASI02 Tool Misuse and Exploitation | Tool allow-list per agent, model allow-list, per-hour, per-day and per-task budgets, rate throttle, account-number masking, high-risk tools fail closed on stale policy (`policy.ts`, `services/gateway/src/app.ts`) | `npm test` (gateway: scope, budget, throttle, masking); `make chaos` (control stop) | [runaway-agent.md](../docs/runbooks/runaway-agent.md) |
| ASI03 Identity and Privilege Abuse | Short-lived HMAC identity tokens with a SPIFFE-style subject, token-to-agent binding, revocation, retired agents refused (`services/control/src/identity.ts`). Demo secret is a dev default; SPIRE is the production design (ADR-005). | `npm test` (identity); `make chaos` (issuer down: no call allowed on an expired token); `make acceptance` (DoD3) | [identity-issuer-down.md](../docs/runbooks/identity-issuer-down.md) |
| ASI04 Agentic Supply Chain Vulnerabilities | Admission refuses unregistered agents; `origin` recorded; backend has no runtime dependencies; lockfiles pinned. No signature, SBOM or tool-server attestation check at runtime. | `make acceptance` (DoD4); signing and attestation of agents and tool servers: not implemented, limit | [bad-policy-bundle.md](../docs/runbooks/bad-policy-bundle.md) |
| ASI05 Unexpected Code Execution | The demo tools are mocks and no tool executes code. For real agents that run code, the design recommends an isolated runtime (agent-sandbox). Nothing in this repo sandboxes execution. | not implemented, limit | [kill-and-verify.md](../docs/runbooks/kill-and-verify.md) |
| ASI06 Memory and Context Poisoning | Declared `dataSources` per agent; receipts store an argument hash, not content. No memory store, retrieval filter or context provenance control. | not implemented, limit | [runaway-agent.md](../docs/runbooks/runaway-agent.md) |
| ASI07 Insecure Inter-Agent Communication | Agent-to-agent calls go through the same gateway, so they are authenticated, scoped, budgeted and receipted; the detector finds A2A cycles. No end-to-end message integrity between agents. | `make drill` (ping-pong); `npm test` (detector cycle). Message-level integrity: not implemented, limit | [runaway-agent.md](../docs/runbooks/runaway-agent.md) |
| ASI08 Cascading Failures | Static stability with bounded staleness, event buffer bounded with drop counter, gateway failover in the fleet client, graded containment (soft throttle, hard throttle, kill) | `make chaos` (five game days); `make acceptance` (DoD6) | [control-plane-down.md](../docs/runbooks/control-plane-down.md) |
| ASI09 Human-Agent Trust Exploitation | Kill is proven by an independent probe instead of the agent saying it stopped; owner acknowledgement step; the AML test-generation agent only enqueues for human approval. No interface-level provenance labelling of agent output. | `make acceptance` (DoD3); interface protections against over-trust: not implemented, limit | [kill-and-verify.md](../docs/runbooks/kill-and-verify.md) |
| ASI10 Rogue Agents | Admission refuses unregistered workloads, `unregisteredRunning` is measured, detector, kill with proof, tamper-evident receipts (`services/gateway/src/receipts.ts`). Receipts have no external anchor, so tail truncation is not detected (ADR-008). | `make acceptance` (DoD3, DoD4, DoD7); `make verify` (tamper test) | [receipt-chain-broken.md](../docs/runbooks/receipt-chain-broken.md) |
